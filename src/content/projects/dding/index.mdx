## 문제와 해결 방향

> **문제:** 학식 수요는 늘었지만, 학생들은 매번 학교 홈페이지 → 학식 아이콘 → 주차 → 요일별 메뉴까지 여러 단계를 거쳐야 한다.
>
> **해결:** 학식 정보를 크롤러로 수집해 DB에 저장하고, 메뉴와 평가 정보를 한 페이지에서 확인하게 한다.

## 내 역할과 핵심 기여

- 학교 홈페이지 학식 데이터를 크롤링해 MySQL에 저장하는 흐름 구현
- 저장된 메뉴를 Thymeleaf 페이지에 렌더링하는 백엔드 흐름 구성
- 메뉴별 별점 시스템 구현
- Spring Security + JWT 인증 구조와 JPA 기반 데이터 관리 구조 설계

## 아키텍처

**학교 홈페이지 → 크롤러 → MySQL 저장 → Spring Boot 조회 → Thymeleaf 렌더링 → 메뉴별 별점**

Spring Boot MVC 패턴으로 Controller, Service, Repository의 책임을 나누고, 메뉴 데이터가 평가 데이터와 연결될 수 있도록 저장 구조를 설계했습니다.

## 주요 구현

1. **학식 크롤러** — 주차·요일별 메뉴를 수집해 서버에서 쓸 수 있는 형태로 정리
2. **저장과 렌더링** — 학교 홈페이지를 탐색하지 않고도 서비스 화면에서 메뉴 확인
3. **메뉴별 별점** — 단순 조회를 넘어 메뉴별 만족도를 확인하고 학식 선택에 참고
4. **인증과 데이터 관리** — Spring Security + JWT 인증, JPA로 사용자·메뉴·평가 데이터 관리
